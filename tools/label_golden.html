  • Pick the highest-severity problem; tie → first mentioned.
  • Positive review → first specific praised feature; general praise = other.
  • Paid plan mentioned alone ≠ billing. Crash for a paying user = playback.

Intent (precedence)

  • cancellation leaving/uninstalling/cancelling or threatening to
  • complaint negative experience, incl. mixed; generic "bad app"
  • request desired change, no failure reported
  • praise
  • unclear meaningless/unrelated; bare boycott slogans unless product complaint or personal departure

Severity

1
no problem: praise, unclear, pure request
2
dislike, generic criticism, minor annoyance
3
degraded/restricted function, some use remains
4
core task clearly blocked (can't log in / play)
5
explicit serious financial, privacy or data harm

Stars, angry words or cancellation intent alone don't raise severity. Missing context → tick needs_review.
